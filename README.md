# MobileApps-Rec
Basic audio recorder for Android (local storage).
Source code not included as app is from MIT App Inventor space.

> Go to release v1.0
> Download Rec.apk
> Check hash value (SHA256)
> Scan app when prompted by Google before installing
> Install app
